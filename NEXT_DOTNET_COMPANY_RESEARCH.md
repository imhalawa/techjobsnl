# Next Netherlands .NET company sources

Checked **14 August 2026**. Centric is excluded because it has already been added. TechPays was used only for candidate discovery; every result below was validated against a first-party careers page, vacancy feed, job detail, or company page.

## Recommendation

Add **CM.com next**. It is the only candidate here whose official complete feed can reuse an adapter already in the repository: `RecruiteeSource`. The feed currently has **20 global offers**, **11 with a Dutch office**, and **2 live Dutch .NET roles**.

Then add **Yuki**, **Exact**, and **AFAS**. They have strong .NET evidence and complete first-party vacancy sets, but each needs a small new source implementation. Wolters Kluwer, ChipSoft, and NS are useful later; their sources are larger or require more custom parsing.

## Practical order

1. **CM.com** — existing Recruitee adapter; one configuration, fixture, and live completeness test.
2. **Yuki** — smallest useful new adapter; its official JSON feed already contains complete details and JobPosting metadata.
3. **Exact** — reuse the existing `paged-html` configuration idea and validate the visible total across all offsets.
4. **AFAS** — parse the structured OutSite payload and assert `firstPage`, `lastPage`, and unique vacancy URLs.
5. **Wolters Kluwer** — add Workday only when a second Workday company is ready to justify the adapter.
6. **ChipSoft**, then **NS** — both are complete, but require many detail fetches and custom validation.

## Exclusions

- **Centric:** excluded because it was already merged while this research was running.
- **Keylane:** the official board has current Dutch engineering work, but the current roles are primarily Java; it does not meet the .NET priority.
- **Netcompany:** the current Dutch vacancy pages do not prove that the Dutch roles use .NET; group-level .NET material is insufficient.
- **ProRail:** no current first-party C#/.NET vacancy or stack evidence was verified.
