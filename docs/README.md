# Documentation

TechJobsNL is primarily a local job finder: review Netherlands tech vacancies directly or use observed skills and other posting facts to find matching jobs. Analytics adds context from the same vacancies. Use this index to find the smallest guide that answers your question.

| [Architecture](ARCHITECTURE.md) | High-level diagrams, data flow, scan outcomes, storage, analytics, and test boundaries |

| [Contributing](../CONTRIBUTING.md) | Setup, development checks, source-adapter rules, and pull requests |
